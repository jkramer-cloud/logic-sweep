# Logic Sweep v1.2 — Mossy Meadow Board

The complete standalone playable game. Open `index.html` directly in Chrome, or upload the entire folder contents to a GitHub repository with Pages enabled. The new `assets/` folder must stay beside `index.html` for Meadow graphics to load. All assets are bundled: no network connection is required.

## New: real illustrated game board

Meadow is a fifth selectable theme based on a cozy woodland Minesweeper board. The background is a garden landscape; every raised earthen tile is its own interactive button. Revealed squares turn into alternating textured grass; flags are red pennants; discovered mines feature an illustrated mole. Numbers and mine locations are always generated by the original game logic, **not painted into the scenery**. The first click, controls, wins/losses, hint logic, shields, sounds, custom sizes, and original four themes remain intact.

The environment is an illustrated 2.5D approximation, not true WebGL 3D: a close resemblance to the reference in colors, materials and atmosphere, but it is not a pixel-perfect reproduction of a cinematic 3D render.

Select **Meadow** from the world picker. Existing browser theme preferences are respected, so a returning player may need to switch to Meadow once. Reduced-motion preferences remain supported.

## Files

- `index.html` — complete game, including all five themes and original logic
- `assets/meadow-scene.webp` — standalone woodland background with no board or fake clues
- `assets/earth-0.webp` through `earth-3.webp` — raised soil tile artwork
- `assets/grass-0.webp` through `grass-3.webp` — revealed ground artwork
- `assets/meadow-flag.svg` — red flag that appears on flagged tiles
- `assets/meadow-mole.svg` — mine creature icon

## Repository publishing

Suggested repository: `logic-sweep`. Extract this ZIP and upload `index.html`, `README.md` and the entire `assets/` folder to the repository root. Enable Pages → deploy from `main` branch, `/(root)`. Site URL should then be `https://jkramer-cloud.github.io/logic-sweep/`.

This package only updates the standalone Logic Sweep game. It does **not** modify PlayForge. When your PlayForge card already points to the same Logic Sweep repository URL, no PlayForge homepage update is needed.

## Controls

Left-click / tap: reveal (or flag when Flag is selected). Right-click: flag. Long press on touch: flag. F on focused tile: flag. Click a revealed number with the correct number of neighboring flags to open its remaining neighboring tiles. Deduction Coach uses visible numbers only.
